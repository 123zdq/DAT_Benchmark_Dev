算法部分介绍

You can choose language by



本项目提供了3种环境类的实现，以及4种baseline算法，可供用户后续进行算法设计和性能比较 环境类详细文档参考: 环境封装 ；算法类详细文档参考： 环境封装

快速开始(运行baseline算法)

Baseline1: BenchEnv_Multi 环境 + A3CLSTM-E2E 算法

环境代码见 Alg_Base/rl_a3c_pytorch_benchmark/envs/environment.py 算法代码见 Alg_Base/rl_a3c_pytorch_benchmark/models/A3CLSTM_E2E/

可以运行如下代码快速开启算法：

cd Alg_Base/rl_a3c_pytorch_benchmark/
python ./models/A3CLSTM_E2E/main.py

Baseline2: Envs 环境 + CVAT 算法

环境代码见 Alg_Base/rl_a3c_pytorch_benchmark/envs/gym_envs.py 算法代码见 Alg_Base/rl_a3c_pytorch_benchmark/models/D_VAT/

可以运行如下代码快速开启算法：

cd Alg_Base/rl_a3c_pytorch_benchmark/
python ./models/D_VAT/DVAT_main.py

Baseline3: UAV_VAT/UAV_VAT_Gymnasium 环境 + D-VAT 算法

环境代码见 Alg_Base/rl_a3c_pytorch_benchmark/envs/envs_parallel.py 算法代码见 Alg_Base/rl_a3c_pytorch_benchmark/models/Recurrent_PPO/

可以运行如下代码快速开启算法：

cd Alg_Base/rl_a3c_pytorch_benchmark/
python ./models/Recurrent_PPO/RPPO.py
